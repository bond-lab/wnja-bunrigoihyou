Background

The project links two Japanese sense inventories. The Japanese WordNet (wnja 2.1) groups words into synsets, each with a definition and sometimes an example. The 分類語彙表 (WLSP, Word List by Semantic Principles) is a thesaurus: every headword occurrence is a record with a position in a four-level category tree (類 / 部門 / 中項目 / 分類項目) and, below that, a 段落 (paragraph) and a 小段落 (sub-paragraph) of near-synonyms. One sense of a headword is a 見出し番号; its canonical record is what the code calls db.senses[mid].

candidates.py has already paired every wnja sense with the WLSP senses whose written form (or reading) matches its lemma, and scored the overlap of their neighbourhoods. The table this script reads and rewrites, build/candidates.parquet, holds 168,540 candidate pairs for 96,223 wnja senses (33,159 synsets) and 47,235 WLSP senses. The structural features cannot tell apart two WLSP records of the same word whose neighbourhoods both miss the wordnet's vocabulary; 60,426 pairs are the only candidate of their sense and carry no contrast at all. Tier 2 adds a second opinion from meaning: does the text of the synset read like the text of the record?

Sentence embeddings, in two sentences

A sentence-embedding model maps a string to a vector of fixed length (384 floats for multilingual-e5-small) so that strings with similar meaning point in similar directions. With normalize_embeddings=True every vector has length 1, so the dot product of two vectors is their cosine similarity: 1.0 for identical direction, lower as they diverge. The model is multilingual, so a Japanese definition can be compared with an English category name in one space.

The e5 family expects a role prefix on each string: query: on the thing being searched for and passage: on the things searched. The script passes them as --query-prefix (synset side) and --doc-prefix (WLSP side); other models, such as BAAI/bge-m3, take none.

read_category_names() (features_sent.py:64-76) is a plain csv.DictReader over the tab-separated file, keeping the Code and en columns. If the file is absent the mapping is empty and the cat text is the bare labels.

The leak to avoid. --tufs-gloss ../tufs/tufs-vocab.tsv (features_sent.py:79-108, applied at :158-160) appends an English gloss to the sub and ctx texts of the 847 WLSP records that are TUFS concepts, for example 手: お手手、上肢 (arm, hand) and 走る: 走らす・走らせる、走行する (run). Those 847 records are the dev set (TUFS concept ID = WLSP record ID), so the gold rows get an English hint that no other row gets, and any evaluation with it on is meaningless. The script logs a warning (:335-339) but does not stop you. Use it for the final mapping only, never for evaluate.py. The run described on this page did not use it.

Why the cosines need rel_*

Every value this script writes lives in a narrow band. Over all 168,540 rows the medians are 0.852 (_cat), 0.871 (_sub) and 0.874 (_ctx); 90% of rows fall between about 0.81 and 0.91. Gold rows average only 0.02 to 0.035 above labelled negatives:

Rows (dev-labelled)n_cat_sub_ctxchive_sub_max
gold = 15870.8580.8770.8790.691
gold = 0 (other senses of the word, decoys)1,8610.8390.8420.8480.285
all rows, 5th to 95th percentile0.812 to 0.8880.819 to 0.9080.823 to 0.914

This is normal for e5-small: a model trained for retrieval places all Japanese dictionary-like text in one small cone, and absolute cosine says more about the text style than about the pair. Within one wnja sense, the spread between its best and worst candidate is small too: median 0.015 to 0.016 over the 36,375 senses with two or more candidates. A tree model splitting on the raw column sees mostly noise, and the README records the result: adding the raw e5 columns to core + chiVe moved lenient top-1 from 0.767 to 0.754, inside the noise of 303 senses.

The fix lives in score.py, not here. add_derived() subtracts, for every chive_* and sent_* column, the maximum over the same sense_id, giving rel_sent_… columns that are 0 for the best candidate of a sense and negative for the rest. For 走る:

code             gold_rel  rel_sent_…_cat  rel_sent_…_sub  rel_sent_…_ctx
2.1522-02-01-01  exact      0.000           0.000           0.000
2.1531-03-05-02  decoy     -0.030          -0.019          -0.020
2.3841-01-01-04  decoy     -0.035          -0.076          -0.034

Expressed that way, the e5 category similarity became the scorer's most used feature and many-to-many precision/recall at 0.5 rose from 0.83/0.86 to 0.87/0.89 (README, 2026-11-05). The script itself does not know about any of this: it writes raw cosines, and that is the right division of labour, since the relative view depends on which other candidates a sense has.

4. The embedder and its cache

features_sent.py:164-194, 341-344 
from sentence_transformers import SentenceTransformer    # :184

self.model = SentenceTransformer(model, device=device, trust_remote_code=True)

The import is inside __init__ so that the module can be imported (for its text functions, as this page did) without torch installed. The cache is a dict from text to vector, loaded whole; allow_pickle=False means the texts are stored as a fixed-width unicode array, not Python objects. --device is passed straight through: mps on a Mac, cuda, or cpu; None lets sentence-transformers pick.

5. Encoding with de-duplication

features_sent.py:196-219 
keyed = [prefix + t for t in texts]                               # :206
todo = sorted({k for k in keyed if k not in self.cache})          # :207
if todo:
    vecs = self.model.encode(todo, batch_size=self.batch_size,
                             normalize_embeddings=True, ...).astype(np.float32)
    self.cache.update(zip(todo, vecs, strict=True))
return np.vstack([self.cache[k] for k in keyed])                  # :219

Three things happen here. The prefix becomes part of the cache key, so query: 走る… and passage: 走る… are different entries and a run with other prefixes cannot pick up stale vectors. Duplicate texts are embedded once: the cat text is shared by every record in a 分類項目, so 47,235 records produce only 889 distinct cat strings. And the return keeps the caller's order and length, duplicates included, so the caller can index it positionally.

Synsets are embedded once each (33,159 texts), not once per sense: two senses of one synset share a vector. Only the WLSP senses that appear with the chosen synsets are rendered, which is what makes --max-texts 500 a quick smoke test. VARIANTS = ("cat", "sub", "ctx") (:49) fixes the order everywhere. The cache is saved right after encoding, before the cosines, so a crash later still keeps the expensive part.

7. Three dot products per row

features_sent.py:279-288 
si = np.array([s_index.get(s, -1) for s in df["synset_id"]])
wi = np.array([w_index.get(m, -1) for m in df["midashi_no"]])
ok = (si >= 0) & (wi >= 0)

    vals = np.full(len(df), np.nan, dtype=np.float32)
    vals[ok] = np.einsum("ij,ij->i", s_vec[si[ok]], w_vec[v][wi[ok]])      # :285
    cols.append(pl.Series(f"sent_{tag}_{v}", vals, dtype=pl.Float32).fill_nan(None))

Each row of the table looks up its synset vector and its WLSP vector by position; einsum("ij,ij->i") is the dot product of matching rows, which on unit vectors is the cosine. Rows outside the subset (a smoke test) get NaN, turned into a proper null by fill_nan(None). Any existing columns for this tag are dropped first, so re-running a model replaces its columns rather than failing on a duplicate name.

The embedding cache

build/emb/multilingual_e5_small/cache.npz after the one CPU run: 127,670 texts with 384-dimensional float32 vectors, 392 MB on disk. The keys carry their prefixes:

texts    127670  (33157 "query: …" + 94513 "passage: …")
vectors  (127670, 384) float32, every row of length 1.0

query:   走る、駆ける: ランニングにより補う; 特定の距離を走る 例: 彼女は、その日、10マイル走った
passage: 用 関係 作用 走り・飛び・流れなど (Action)
passage: 走る: 走らす・走らせる、走行する
passage: 体 自然 身体 手足・指 (Body)

The arithmetic: 33,159 synsets collapse to 33,157 query texts (two pairs of synsets render identically: 教諭: 教師の地位 and 推敲: 文章や詩について… each occur twice), and the 47,235 WLSP senses give 889 + 46,684 + 46,940 = 94,513 distinct passage texts. Re-running the same model with the same prefixes embeds nothing new and finishes in the time it takes to load the file and take 505,620 dot products. A different model, or --en-gloss (which changes every synset text), starts its own folder or its own entries.

How much to trust this

This page was written by an AI from the source file. That makes it fast to produce and easy to refine, and also fallible: a model can misread a line, invent a plausible detail, or keep a number that has since changed.

So treat the code as the source of truth and this page as a guide to it:

  • Every code claim carries a file:line reference into scripts/features_sent.py or scripts/wlsp.py at commit b3e6896; open it and check. The mechanical checker (explainer_check.py) was run on this page.
  • The texts for 走る and 手 were produced by importing synset_text() and wlsp_texts() from the script and calling them on the real data (wnja 2.1, WLSP 1.0.1, bunrui_names.tsv); no model was loaded for this page.
  • The cosines, means, percentiles and counts were read from build/candidates.parquet and the cache file as of 2026-11-05 with the snippets in the appendix. They describe one run of multilingual-e5-small on CPU. Another model, --en-gloss, or a rebuilt candidate table will change every number.
  • The evaluation figures (0.767 to 0.754 top-1, 0.83/0.86 to 0.87/0.89 P/R) are copied from the README's table and dev/eval.md, not recomputed.
  • The surest check is to run the script with --max-texts 50 and compare the cached texts with the ones shown here.
  • The quiz answers are derived from the code; where one disagrees with the code, the code wins. Please report it.

類 / 部門 / 中項目 / 分類項目the four label levels, 用/関係/作用/走り・飛び・流れなど; the 中項目 code (2.15) is what gets an English name (Action).
段落 / 小段落paragraph and sub-paragraph inside a 分類項目; 小段落 members are close synonyms (走らす・走らせる、走行する), 段落 members related (独走する、疾走する …).
cat / sub / ctxthe three WLSP texts: category path with English name; headword with 小段落 neighbours; path, headword, 小段落 and up to 20 段落 neighbours.
cosine similaritythe dot product of two unit vectors; here between 0.71 and 0.95, mostly 0.81 to 0.91.
tagmodel_tag() of the model name: multilingual_e5_small. Names the columns and the cache folder.
decoya wrong candidate added by candidates.py for dev senses (gold_rel = decoy): a WLSP sense of another word in the same 類, such as 染め上げる for 走る.
rel_*a feature minus its maximum over the sense, computed in score.py; what turns the narrow cosine band into a usable signal.

Background

The project links two Japanese sense inventories that were built on different principles. The script's job is the first step: list every pairing that could be right, and attach evidence, so that score.py can decide later.

The Japanese WordNet (wnja 2.1)

A wordnet groups words into synsets, sets of synonyms sharing one meaning. wnja 2.1 has 90,696 words, 148,679 senses and 67,509 synsets (len(ja.words()) and friends). A word is a lemma with a part of speech and some written forms; a sense is one word in one synset. The verb 会う is one word (wnja-v-13725) with nine senses:

The word also carries written forms: w.forms() for 会う is ['会う', 'アウ', '逢う', '遇う', '遭う', 'あう']. Kanji variants and kana readings are mixed in that list, and the script has to treat them differently (see word forms).

Each wnja synset carries an ILI (interlingual index) id such as i31856, shared with the English wordnet omw-en:1.4. wnja itself has few hierarchy links, so the script fetches hypernyms and hyponyms from the English side through the ILI. 分類語彙表 (WLSP)

The Word List by Semantic Principles is a thesaurus: 101,067 records arranged by meaning, not by spelling. A headword that has several spellings or readings is a parent record of type B followed by numbered children that share its 見出し番号; wlsp.py treats the 見出し番号 as the sense (96,051 of them) and merges the children's forms into it (wlsp.py:220–223). The entry 80089 is three records:

record_id  type  midashi          yomi
084043     B     あう（会・遭）     あう      ← canonical entry, lemma "あう"
084044     1     会う              あう
084045     2     遭う              あう
→ db.senses["80089"].lemma == "あう";  db.forms["80089"] == {"あう", "会う", "遭う"}

Every record has a position code, 類.部門中項目分類項目-段落-小段落-語番号 (wlsp.py:66–69). For 80089 it is 2.3520-01-01-01: 類 2 is 用 (verbs), 2.35 the 中項目 交わり, 2.3520 the 分類項目 応接・送迎, then 段落 01, 小段落 01, word 01. The first digit maps to a wordnet part of speech by RUI_TO_POS (wlsp.py:45): 1 → n, 2 → v, 3 → a, 4 → r. The code gives four nested groups the script will compare against, from tight to loose; here with the group sizes for 80089:

Over the whole database there are 32,195 小段落, 9,909 段落, 895 分類項目 and 95 中項目 (len(db.groups[level])). A 小段落 holds close synonyms, a 段落 related senses, a 分類項目 a topic.

The problem: polysemy on both sides

WLSP lists あう three times: 69369 (2.1550 合体・出会い・集合, "come together"), 80089 (2.3520 応接・送迎, "meet someone") and, spelled 遭う, 77441 (2.3310 人生・禍福, "meet with misfortune"). wnja has nine senses. The script does not pick: it emits all 9 × 3 = 27 pairs for 会う and leaves the choice to the features. Across wnja that gives 168,540 pairs for 96,223 senses of 47,112 words (of 90,696; the rest match no WLSP headword, counted by running find_candidates over ja.words()), against 47,235 distinct WLSP senses. 60,426 of the pairs are the only candidate of their sense.

Intuition

A wnja sense and a WLSP sense are the same meaning when the words around them agree. Around the synset: its other members, its hypernyms, hyponyms and siblings (from English via ILI), and its similar and antonym synsets. Around the WLSP record: the four nested groups. Every feature is the size of one intersection.

Synset neighbourhood
  • syn other members
  • hyper hypernyms, via ILI
  • hypo hyponyms, via ILI
  • sib co-hyponyms, via ILI
  • sim similar, also (wnja)
  • ant antonym (wnja)
∩ov_<rel>_<level>

Not every relation is crossed with every level: synonyms are checked down to the 小段落 but hypernyms only from the 段落 up, because a hypernym is related, not synonymous (OVERLAPS, candidates.py:47–64). All strings are compared after fold(): NFKC and katakana → hiragana (wlsp.py:138–147), so レスト and れすと count as one.

Reading the feature vector

Each row carries 16 overlap counts, six neighbourhood sizes (n_syn … n_ant) and four group sizes (size_subpara … size_middle), so a scorer can judge "3 of 45" against "3 of 6". The sizes are per synset or per record and do not change across a sense's candidates; the overlaps do.

2 · Written forms and readings

candidates.py:80–125 · wlsp.py:138–147

Three small functions decide what counts as a spelling of a wnja word and what counts as a reading.

def is_kana(text: str) -> bool:
    return bool(text) and all("ぁ" <= c <= "ゟ" or "゠" <= c <= "ヿ" or c == "ー" for c in text)

def word_forms(word: wn.Word) -> set[str]:
    lemma = word.lemma()
    out = {fold(lemma)}
    out.update(fold(f) for f in word.forms() if not is_kana(f) or is_kana(lemma))
    return out

def kana_forms(word: wn.Word) -> set[str]:
    return {fold(f) for f in [word.lemma(), *word.forms()] if is_kana(f)}

The condition on line 112 is the subtle one: a kana form is kept as a spelling only when the lemma itself is kana (ドウゾ), otherwise it is a reading. fold explains why アウ and あう collapse: fold("コーヒー") is "こーひー", fold("ﾊﾞｽ") is "ばす". Note that is_kana("ー") is True and is_kana("") is False.

3 · Synset contexts

candidates.py:128–176

One pass over all 67,509 wnja synsets collects, per synset, the folded forms of its members and of six kinds of related synset into a SynsetContext (:92–97). The first loop (:144–150) also builds by_ili, ILI → wnja synset id, which is how English neighbours are brought back into Japanese:

def ja_forms(en_synsets: list[wn.Synset]) -> set[str]:
    out: set[str] = set()
    for es in en_synsets:
        jid = by_ili.get(es.ili or "")
        if jid:
            out |= contexts[jid].forms
    return out

Then, per synset (:160–175): similar and also links feed sim, antonym feeds ant, both read from wnja itself. If the synset has an ILI, the matching omw-en synset supplies hypernyms() plus instance_hypernym → hyper, hyponyms() → hypo, and the other hyponyms of each hypernym → sib. Finally the synset's own forms are removed from hyper, hypo and sib (:174–175), so a word that is both a member and a hyponym is not counted twice.

For 先生 wnja-10694258-n this gives n_hyper = 2, n_hypo = 17, n_sib = 32, n_sim = n_ant = 0. Synsets with no ILI (2,231 rows in the table have ili == "") get no hierarchy at all. Only 18,821 rows have any sim forms and 17,362 any ant forms: those links are sparse in wnja.

4 · Finding candidates

candidates.py:179–204 
def find_candidates(word: wn.Word, db: Wlsp) -> dict[str, str]:
    found: dict[str, str] = {}
    lemma = fold(word.lemma())
    for mid in db.by_form.get(lemma, []):
        found[mid] = "lemma"
    for f in word_forms(word) - {lemma}:
        for mid in db.by_form.get(f, []):
            found.setdefault(mid, "form")
    if word.pos == "v" and lemma.endswith("する"):
        for mid in db.by_form.get(lemma[:-2], []):
            found.setdefault(mid, "suru")
    if not found:
        for y in kana_forms(word):
            for mid in db.by_yomi.get(y, []):
                found.setdefault(mid, "yomi")
    return found

Four match types, tried in order; setdefault keeps the first, so a record reached by the lemma stays lemma even if a form reaches it too. The reading fallback runs only when nothing else matched. Counts over the whole table: lemma 114,567 rows, yomi 43,357, form 9,836, suru 780.

A side effect worth knowing. Because kana forms of a kanji lemma are readings, a WLSP headword written in kana (ちょうど, あう as a parent) is reached either through a kanji child record or through the yomi fallback, never as a form. The fallback is all-or-nothing per word: it adds every homophone (調度) once it runs.

5 · Pair features

candidates.py:207–230 
def pair_features(ctx: SynsetContext, own: set[str], rec: WlspEntry, db: Wlsp) -> dict[str, int]:
    groups = {level: db.group_forms(rec, level) for level in LEVELS}
    sets = dict(ctx.related)
    sets["syn"] = ctx.forms - own
    out: dict[str, int] = {}
    for rel, level in OVERLAPS:
        out[f"ov_{rel}_{level}"] = len(sets[rel] & groups[level])
    for rel in RELATIONS:
        out[f"n_{rel}"] = len(sets[rel])
    for level in LEVELS:
        out[f"size_{level}"] = len(db.groups[level][db.group_key(rec, level)])
    return out

db.group_forms(rec, level) (wlsp.py:276–289) is the union of folded forms of every sense in the record's group at that level. own is the word's own forms, removed from the member set so that the headword being matched never counts as evidence for itself. 6 · Gold labels and their grades

def gold_relation(mid: str, golds: set[str], db: Wlsp) -> str:
    if mid in golds:
        return "exact"
    rec = db.senses[mid]
    for level in ("subpara", "para", "item"):
        key = db.group_key(rec, level)
        if any(db.group_key(db.senses[g], level) == key for g in golds):
            return f"same_{level}"
    return "other"

        if len(out) >= k or not mids:
            break
        mid = mids[rng.randrange(len(mids))]
        rec = db.senses[mid]
        if rec.item_key in taken or db.forms[mid] & word_forms_ or mid in out:
            continue
        out.append(mid)
    return out

A decoy is drawn from the WLSP senses of the same 類 as the sense's part of speech (by_pos: n 64,584, v 21,682, a 8,915, r 870), skipping any 分類項目 one of the word's real candidates occupies, any record that shares a spelling with the word, and repeats. For 紅 the taken 分類項目 are {1.5020, 1.4370, 1.1962, 1.3075}; the draw gave 38737 急用 (1.3460) and 27669 食品学 (1.3074). The seed is fixed (seed=0), so a rerun picks the same decoys. 594 senses received exactly two decoys; the other 2 of the 596 dev senses with candidates, ええ and いかが, have part of speech x, for which by_pos has no entry (WLSP 類 digits map only to n, v, a, r), so mids is empty and the loop breaks at once.

In build the decoy is disguised (:376–381): its lex is set to the match type of the word's first real candidate, so the only difference from a real candidate lies in the pair features. 丁度's decoys よもや and がちゃがちゃ are stamped yomi. The filter is at 分類項目 level only: 先生's decoy 漁民 (1.2413) shares the 中項目 1.24 with the gold, and so has ov_hyper_middle = 2 and ov_hypo_middle = 6.
